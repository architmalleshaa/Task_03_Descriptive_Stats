# Statistical conventions and result format

All engines use the same input contract and independently aggregate values. The shared module defines parsing, type decisions, tie breaking, and serialization. Pure Python computes arithmetic with the standard library; Pandas uses Series statistics, `describe`, `value_counts`, `nunique`, and `groupby`; Polars uses expressions, `describe`, `value_counts`, `n_unique`, and `group_by`. Agreement validates the implementations under this contract, not the truth of the underlying data or the contract's scientific appropriateness.

- CSV values are read as strings before normalization, preserving identifiers. Default encoding is UTF-8 with optional BOM. `--encoding` selects another encoding; decoding errors fail visibly rather than replacing characters.
- Whitespace is stripped. Empty text and case-insensitive `NA`, `N/A`, `NaN`, `null`, `none`, and `-` are missing. Zero is a valid observation. If these tokens are meaningful categories in a different source, revise the explicit `MISSING` policy before analysis.
- Identifier names such as `page_id` and `id` remain categorical. `--categorical COLUMN` and `--numeric COLUMN` provide deliberate overrides. Numeric inference requires every present value to parse; a mixed column remains categorical and its parseable count is reported. A forced numeric override rejects bad values.
- Numeric parsing accepts finite decimal/scientific values, properly grouped thousands separators, leading dollar signs, accounting parentheses, and percentages converted to fractions. It does not convert currencies or infer units. Unexpected mixed units require domain review.
- Numeric summaries exclude missing values. Standard deviation defaults to the sample convention (`ddof=1`); fewer than two values yield null. `--ddof 0` requests population deviation. Means, minima, maxima and medians of empty numeric columns are null.
- Empty columns have type `empty`, count and unique count zero, null mode, and an empty top-five list. Boolean text remains categorical. ISO date-like text is recognized only when valid; other dates remain categorical and can be interpreted separately.
- Lists and dictionaries remain structured text in generic summaries. Their frequencies describe serialized strings, not constituent elements. The separate domain analysis uses `ast.literal_eval`, never `eval`, to parse spending bounds and mention lists.
- All ties in categorical frequencies are resolved lexicographically. Missing values are excluded from modes and unique counts but retained as a separate group when a grouping key is missing.
- `summary.json` contains dataset dimensions, source SHA-256, inferred types, missing counts/percentages and every column statistic. `native_structure.txt` records the engine's loaded structure. The console prints a readable summary.
- Each `groups_N.jsonl.gz` begins with metadata, then one record per group in a stable order. Multirow groups contain the full column summary. Single-row groups use `singleton_statistics_v1`: each stored value deterministically represents all statistics. For a present numeric x, count=1, mean=min=max=median=x and sample std=null (population std=0). For a present categorical x, count=unique=mode_frequency=1 and top5=[[x,1]]. Missing values have count=0, missing=1, null numeric statistics or mode, unique=0 and top5=[]. `expand_group.py` expands a selected group for inspection. This exact encoding avoids repeating the same number six times in 246,745 single-ad groups.
- The schema is inferred once for the entire dataset and reused within groups. A group containing only missing values does not change the parent column's type.
- `compare_results.py` compares all dataset statistics and every group, with relative tolerance 1e-10 and absolute tolerance 1e-9 for floating point values. Names, categorical frequencies, nulls, shapes and keys must match exactly.

The scripts load one dataset into memory. They are reusable in schema, not a claim of unlimited scalability. Full grouped exports are kept out of version control because singleton summaries can reconstruct source rows. Regenerate them locally from the linked data.
